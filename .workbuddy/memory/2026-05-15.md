## 项目：AI 外贸获客工作台 (D:/zijianxin)

### 阅读了项目结构
- Spring Boot 3.3 + Java 17，端口 8080
- 核心功能：客户爬虫搜索 + AI 开发信生成 + SMTP 发送
- 前端：5个配置页 + 2个功能页，支持中英文切换（通过 main.js 的 data-i18n 机制）

### 完成：给所有配置页添加中英文切换支持
修改了以下 6 个文件：
- `ai-settings.html`：添加 data-i18n 属性 + pageTranslations 翻译对象
- `crawler-settings.html`：同上（搜索 API 配置页）
- `crawler-rules.html`：同上（爬虫参数/权重配置页）
- `mail-settings.html`：同上（邮箱 SMTP 配置页）
- `general-settings.html`：同上（通用设置页）
- `settings.js`：添加 `t(zh, en)` 辅助函数，使保存成功/失败提示也支持国际化

实现方式：与 index.html 保持一致，在各页末尾注入 `window.pageTranslations`，所有文本节点加 `data-i18n` 属性，由 main.js 统一驱动切换，无需修改后端。
